## Что умеет

- **Моя волна** с настройками характера, настроения и языка — как в официальном приложении.
- **Мгновенный старт:** трек начинает играть через пару секунд после клика и докачивается во время игры.
- **Переходы без паузы и кроссфейд** между треками.
- **Качество на выбор:** экономия, высокое (MP3 320) или без потерь (FLAC, нужен Плюс).
- **Текст песни** с подсветкой текущей строки; клик по строке — перемотка. Где сервис текста не даёт
  (Spotify, свои файлы, часть треков Яндекса), он берётся из открытой базы [LRCLIB](https://lrclib.net).
- **Поиск** по трекам, артистам, альбомам и плейлистам.
- **«Мне нравится», плейлисты, страницы артистов и альбомов**; создание, переименование и удаление плейлистов.
- **Очередь:** перетаскивание, «играть следующим», «в конец очереди», удаление.
- **Интеграция с Windows:** обложка в оверлее громкости и на экране блокировки, кнопки Bluetooth-наушников, медиаклавиши, трей, автозапуск.
- **Мини-плеер** поверх всех окон, **глобальные сочетания клавиш**, **статус в Discord**.
- **Эквалайзер** на 10 полос с пресетами, выбор устройства вывода, визуализатор спектра.
- **История** прослушиваний и продолжение с того же места после перезапуска.
- **Автообновление** из GitHub Releases с проверкой подписи. Если новая версия падает при запуске — Undertone сам
  вернёт прошлую. **Бета-тестирование** (Настройки → Обновления) — новые возможности раньше релиза.
- **Сообщить об ошибке** (Настройки → Диагностика): журналы собираются в архив, открывается страница на GitHub
  с уже заполненными версией и системой.
- **Эффекты:** slowed + reverb, super slowed, speed up, nightcore и 8D-звук — одной кнопкой в нижней панели, со своей скоростью и эхом.
- **Итоги** как Spotify Wrapped: минуты, артист и трек №1, топ-5, время суток, рекорды — за месяц, год или всё время; итоговую карточку можно сохранить картинкой.
- **Spotify** вторым аккаунтом (нужен Premium): лайки, поиск, плейлисты, альбомы, артисты. Звук играет встроенный плеер Spotify
  (устройство «Undertone»), а если он не запустится — приложение Spotify на ПК или телефоне через Spotify Connect.
  Эквалайзер, эффекты, кроссфейд и офлайн к Spotify не применяются — Spotify не отдаёт звук сторонним программам.
  Рекомендации Spotify сторонним приложениям закрыл, поэтому Undertone собирает их сам: **Моя волна** (учится на пропусках
  и дослушанных треках), **миксы** на странице «Подборки» (Ежедневный, Открытия, по жанрам и артистам) и **Похожие**.
  Ключ приложения Spotify (Client ID) вводится прямо на экране входа — там же Redirect URI и ссылка на Spotify Dashboard.

## Установка

1. Скачай `Undertone-Setup-X.Y.Z.exe` со [страницы релизов](https://github.com/Reuz0201/Undertone-app/releases/latest) и запусти.
   Права администратора не нужны, .NET ставить не нужно.
2. Или распакуй `Undertone-win-x64.zip` в любую **свою** папку (не в Program Files) и запусти `Undertone.exe`.
3. Выбери сервис: **Яндекс Музыка** (вход по коду на ya.ru/device) или **Spotify** (вход через браузер).
   Токены сохранятся в зашифрованном виде. Второй сервис подключается позже — клик по профилю внизу слева.

**SoundCloud** пока выключен: ключи его API выдают только с платной подпиской Artist Pro. Код на месте —
включается флагом `MusicServices.SoundCloudEnabled` в `Undertone/Core/MusicService.cs`.

Когда ключи будут: зарегистрируй приложение на soundcloud.com/you/apps с Redirect URI `http://127.0.0.1:47823/callback`.
Client ID и Client Secret вводятся на экране входа (секрет хранится зашифрованным), или их можно вписать в
`%LOCALAPPDATA%\Undertone\.env` руками (пример — в `.env.example`), или вшить в релизную сборку секретами репозитория
`SOUNDCLOUD_CLIENT_ID` и `SOUNDCLOUD_CLIENT_SECRET`. Целиком играются треки, которые автор открыл для всех;
треки Go+ — 30-секундный фрагмент. Моей волны, «Не нравится», FLAC и текстов у SoundCloud нет.

**Требования:** Windows 10 версии 1809 или новее, 64-бит. Для полных треков нужна подписка Яндекс Плюс —
без неё Яндекс отдаёт только 30-секундные фрагменты.

## Горячие клавиши

В окне приложения:

| Клавиша | Действие |
|---|---|
| Пробел | Играть / пауза |
| ← / → | Перемотка на 5 с (с Shift — 15 с) |
| Ctrl + ← / → | Предыдущий / следующий трек |
| Ctrl + ↑ / ↓ | Громкость |
| N / P | Следующий / предыдущий |
| L / D | Нравится / не рекомендовать |
| S / R / M | Перемешать / повтор / без звука |
| W | Моя волна |
| T | Текст песни |
| E | Эффекты (slowed + reverb, speed up, 8D) |
| Y | Итоги |
| 1 … 6 | Сейчас играет / Мне нравится / Поиск / История / Друзья / Настройки |
| Ctrl + F | Поиск |
| Backspace | Назад со страницы артиста или альбома |

Глобальные (работают, даже когда Undertone свёрнут; меняются в «Настройках»):
`Ctrl+Alt+Пробел` — играть/пауза, `Ctrl+Alt+→ / ←` — следующий/предыдущий, `Ctrl+Alt+L` — нравится,
`Ctrl+Alt+↑ / ↓` — громкость, `Ctrl+Alt+U` — показать окно, `Ctrl+Alt+M` — мини-плеер.

## Где лежат данные

Всё в `%LOCALAPPDATA%\Undertone`: токены (`.env`, зашифрованы DPAPI — работают только у тебя на этом ПК),
настройки, кэш музыки (`cache`, размер и очистка — в «Настройках»), журнал ошибок (`logs`),
журнал прослушиваний для итогов (`plays-<id>.log`: только время, id трека и секунды).

## Сборка из исходников

Нужен [.NET 10 SDK](https://dotnet.microsoft.com/download). Запусти `start.bat` — он соберёт и запустит приложение.
Тесты: `dotnet test Undertone.Tests`. Выпуск версии — `publish.bat`, подробности в [RELEASING.md](RELEASING.md).

## Важно

Undertone — неофициальный проект, он не связан с Яндексом. Используется то же API, что и у публичной библиотеки
[yandex-music](https://github.com/MarshalX/yandex-music-api). Пожалуйста, слушай музыку по своей подписке.
