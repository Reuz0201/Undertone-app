# Выпуск новой версии

1. Закоммить изменения и запушь их.
2. Поставь тег с номером версии (строго `vX.Y.Z`, больше предыдущей):

   ```
   git tag v1.1.0
   git push origin v1.1.0
   ```

3. Вкладка **Actions** на GitHub → workflow **Release** соберёт `Undertone.exe`
   и создаст релиз с `Undertone-win-x64.zip` и `.sha256`. Описание релиза
   GitHub составит из коммитов (его можно отредактировать — оно показывается
   в подсказке у кнопки «Обновить»).
4. У всех запущенных копий в течение 6 часов (или при следующем запуске)
   появится плашка «Доступно обновление».

## Установка у пользователя

- Нужен .NET 8 Desktop Runtime: https://dotnet.microsoft.com/download/dotnet/8.0
- Распаковать `Undertone-win-x64.zip` в любую **свою** папку
  (не в Program Files — туда нет прав на запись без администратора).
- Запустить `Undertone.exe`, войти по коду. Токены сохранятся в `%LOCALAPPDATA%\Undertone\.env`
  (старый `.env` рядом с exe перенесётся туда автоматически).
- Крестик сворачивает в трей. Выход — правой кнопкой по значку → «Выход».
- Дальше обновляется само: кнопка «Обновить» в сайдбаре.

## Важно

- Репозиторий должен быть **публичным** — иначе приложение не сможет скачать релиз.
- Запуск через `start.bat` (из исходников) не обновляется автоматически — это режим разработки.
- Источник обновлений вшивается при сборке в CI. Переопределить можно в `.env`:
  `update_repo: owner/repo`.
- Откатиться на старую версию: скачать нужный zip из Releases и распаковать поверх.
