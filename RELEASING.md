# Выпуск новой версии

Запусти `publish.bat` (рядом со `start.bat`) и ответь на вопросы. Скрипт сам:
проверит, что `.env` не попадёт в git, предложит номер версии, соберёт проект
для проверки, закоммитит, запушит, поставит тег и дождётся сборки в GitHub Actions.

Без вопросов: `publish.bat 2.1.0 "Что нового"`.

Перед публикацией закрой версию, запущенную через `start.bat`, иначе пробная сборка
упадёт: exe будет занят.

## Вручную (если скрипт не подходит)

```
git add .
git commit -m "Что нового"
git push
git tag v2.1.0
git push origin v2.1.0
```

## Установка у пользователя

- Нужен .NET 8 Desktop Runtime: https://dotnet.microsoft.com/download/dotnet/8.0
- Распакуй `Undertone-win-x64.zip` в любую **свою** папку (не в Program Files).
- Запусти `Undertone.exe` и войди по коду. Токены сохранятся в `%LOCALAPPDATA%\Undertone\.env`.
- Крестик сворачивает в трей. Выход — правой кнопкой по значку → «Выход».
- Дальше обновляется само: кнопка «Обновить» в сайдбаре.

## Важно

- Репозиторий должен быть **публичным**, иначе приложение не сможет скачать релиз.
- Запуск через `start.bat` (из исходников) не обновляется автоматически: это режим разработки.
