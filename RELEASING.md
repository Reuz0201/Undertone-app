# Выпуск новой версии

Запусти `publish.bat` (рядом со `start.bat`) и ответь на вопросы. Скрипт сам:
проверит, что `.env` не попадёт в git, предложит номер версии, соберёт проект и прогонит тесты,
закоммитит, запушит, поставит тег и дождётся сборки в GitHub Actions.

Без вопросов: `publish.bat 3.0.0 "Что нового"`.

Перед публикацией закрой версию, запущенную через `start.bat`, иначе пробная сборка
упадёт: exe будет занят.

## Что пишется в релиз

- Текст релиза берётся из `CHANGELOG.md`, из раздела `## X.Y.Z`. Его видят пользователи
  в подсказке на кнопке «Обновить», так что перед выпуском допиши туда, что нового.
- Файлы: `Undertone-Setup-X.Y.Z.exe` (установщик), `Undertone-win-x64.zip` (для обновления и ручной установки),
  `.sha256` и, если настроена подпись, `.sig`.
- Сборка self-contained: пользователю не нужно ставить .NET. Плата за это — архив около 70 МБ.

## Вручную (если скрипт не подходит)

```
git add .
git commit -m "Что нового"
git push
git tag v3.0.0
git push origin v3.0.0
```

## Подпись обновлений (один раз)

SHA-256 защищает только от битого файла. Чтобы никто не подсунул пользователям чужой архив,
релизы подписываются ключом:

1. Запусти `pwsh -File tools\new-signing-key.ps1` (нужен PowerShell 7).
2. Содержимое `tools\signing-key.private.pem` — в секрет репозитория `UPDATE_SIGNING_KEY`
   (Settings → Secrets and variables → Actions → New repository secret). Файл после этого удали.
3. Напечатанный публичный ключ — в переменную `UPDATE_PUBLIC_KEY` (там же, вкладка Variables).

Сборки с этим ключом принимают только подписанные им обновления. Не потеряй приватный ключ:
без него придётся выпускать версию с новым ключом, и старые копии не смогут обновиться сами.

## Подпись exe (по желанию)

Без цифровой подписи Windows SmartScreen предупреждает каждого нового пользователя.
Бесплатно для open source можно подать заявку в SignPath Foundation (signpath.org),
платно — Azure Trusted Signing. После получения сертификата подпись добавляется шагом в `release.yml`
перед «Архив и контрольная сумма».

## Важно

- Репозиторий должен быть **публичным**, иначе приложение не сможет скачать релиз.
- Запуск через `start.bat` (из исходников) не обновляется автоматически: это режим разработки.
